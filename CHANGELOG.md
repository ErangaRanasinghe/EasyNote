# Changelog

## [1.0.0] - 2026-11-07

First release.

- Hidden tab on the right edge of the screen opens and closes the note.
- Borderless note window at the bottom centre of the screen, always on top.
- Saves as you type; copy selection or all text; clear with undo.
- Font choice and transparency levels, both remembered.
- Follows light and dark mode.
- Start-up window with logo, version and publisher.
- Tray icon and menu, start with Windows / start at login.
- Windows build (C#, no install needed) and Linux version (Python + GTK) with installer.
